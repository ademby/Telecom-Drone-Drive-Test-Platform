# Operator frontend

Vite + TypeScript + OpenLayers. A full-screen map with a floating operations panel.

```bash
npm run dev:frontend      # from the repository root, http://localhost:5173
npm run frontend:check    # type-check
npm run frontend:build
```

Requires `apps/frontend/.env` with `VITE_API_BASE_URL` (see `.env.example`) and a running backend. Admin boundary data must exist in `public/data/` (generated by `tools/data-pipeline`, see the root README).

## Structure

```text
src/
  main.ts                entry point
  ui.config.ts           build-time rendering defaults (renderer kind, tile size, caches)
  common/                CompositionRoot, OperationsPanel (generic host), PanelView contract
  map/                   MapController, basemaps, shared OL styles
  workflows/
    navigation/          administrative geography: tree, breadcrumbs, location search
    mission/             planning (editor) and result review; owns the mission Http adapters
    heatmap/             Signal Quality layer, legend, palette, renderer, Http adapter
```

Rules: workflows never call each other; they share only `MapController` and `OperationsPanel`; each owns its layers, interactions, controls, panel views and adapters.

Details: [`docs/architecture/frontend.md`](../../docs/architecture/frontend.md). Decisions: ADR-0005, 0006, 0009, 0010, 0011. Diagrams: [`docs/uml/`](../../docs/uml/) 0004 to 0012.

## Development shortcut

While in dev mode, the composition root is available in the browser `Console` as `compositionRoot` (for example `compositionRoot.heatmapWorkflow.refresh()`).
